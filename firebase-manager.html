How to Setup Firebase in 3 Steps

  1. 1

    Create a Project in Firebase Console

    Go to console.firebase.google.com, sign in with your Google account, and click "Add project" (e.g. heritage-db).

  2. 2

    Enable Cloud Firestore

    In the left sidebar, click Build > Firestore Database. Click "Create database", choose your location (e.g. Mumbai asia-south1), and select "Start in test mode".

  3. 3

    Register Web App & Copy Config

    In Project Settings (gear icon), scroll to Your apps, click Web (</>), register it, copy the firebaseConfig object, and paste it into the box on the right.

Recommended Firestore Security Rules

In the Firebase Console under Firestore Database > Rules, paste these rules to allow public product browsing and order placement while securing administrative writes: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Products: anyone can read, anyone can write in dev test mode
    match /products/{productId} {
      allow read: if true;
      allow write: if true; // In production: if request.auth != null
    }
    
    // Artisans: public profiles
    match /artisans/{artisanId} {
      allow read: if true;
      allow write: if true;
    }
    
    // Orders: customers can create orders, read their own
    match /orders/{orderId} {
      allow create: if true;
      allow read: if true;
      allow update, delete: if false;
    }
  }
}
